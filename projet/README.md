# Description du projet

Cette archive est composée des éléments suivants :

* un dossier projet structuré à minima de la façon suivante :
   * un dossier vendeur contenant les fichiers sources pour un agent vendeur 
   * un dossier preneur contenant les fichiers sources pour un agent preneur
   * un dossier marche contenant les fichiers sources pour l’agent Marché
   * un dossier lib contenant les librairies nécessaires (Jade…)
   * un dossier misc contenant les autres fichiers (configs, scripts…)
